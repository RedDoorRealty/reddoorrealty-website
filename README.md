# Red Door Realty website

The site for Red Door Realty (reddoorrealtyme.com), Randy Caron, Portland, Maine.

- `index.html`: the whole site in one file
- `share.jpg`: image shown when the site is shared on Facebook or in texts
- `favicon.png`: browser tab icon
- `netlify.toml`: Netlify publishing settings

Forms use Netlify Forms (`home-value` and `schedule-call`). Set email notifications in Netlify under Site configuration > Forms > Form notifications.
